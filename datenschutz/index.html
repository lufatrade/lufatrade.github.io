Zweck der Anwendung

„LuFatrade Pin Sync“ ist eine interne Automatisierung, die Produktbilder und Produktinformationen aus unserem eigenen Etsy-Shop nutzt, um Pinterest-Pins zu erstellen, die auf unsere Etsy-Produktseiten verlinken. Die Anwendung wird ausschließlich von den beiden Betreibern von LuFatrade selbst genutzt und richtet sich nicht an Endnutzer oder Dritte.

Welche Daten verarbeitet werden

  • Etsy-Shopdaten: über die Etsy Open API abgerufene, öffentlich sichtbare Angaben zu unseren eigenen Listings (Titel, Beschreibung, Bilder, Produktlink, Preis).
  • Pinterest-Kontodaten: über die Pinterest API im Rahmen der OAuth-Autorisierung erstellte Pins (Bild, Titel, Beschreibung, Ziel-Link) auf dem LuFatrade-eigenen Pinterest-Business-Konto.

Es werden keine Daten von Etsy-Käufern, Pinterest-Nutzern oder sonstigen Dritten erhoben, gespeichert oder verarbeitet.

Speicherung

Zugriffstoken (API-Keys, OAuth-Tokens) werden ausschließlich intern zur Anbindung der beiden APIs gespeichert und nicht an Dritte weitergegeben oder verkauft.

Keine Weitergabe an Dritte

Es findet keine Weitergabe der verarbeiteten Daten an Dritte statt, außer soweit dies durch die Nutzung der Etsy- und Pinterest-Plattformen selbst technisch erforderlich ist.
